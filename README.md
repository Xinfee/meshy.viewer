# meshy.viewer — clean-room documentation

Format and interoperability documentation for [Meshy AI](https://www.meshy.ai)
3D exports: the encrypted `.meshy` static container and the plain animated
`*_withSkin.glb` exports.

**This branch contains no implementation.** It holds everything needed to
perform a *clean-room reimplementation* of a viewer/converter: the format
specification, a functional/acceptance spec, and reference test vectors. The
working viewer/converter — the site deployed via GitHub Pages — lives on the
`gh-pages` branch.

All facts documented here were established by **black-box examination of
finished output files** generated by the account owner. No Meshy source code,
binaries, or decompiled material is included or relied upon — the docs state
*what* the files contain and how they behave, nothing else.

## Reading order for a reimplementation

1. [`docs/FORMAT.md`](docs/FORMAT.md) — the binary formats: `.meshy` container
   layout, AES-256-GCM scheme, key material, meshopt payload; plus the
   animated GLB findings.
2. [`docs/CLEAN-ROOM-SPEC.md`](docs/CLEAN-ROOM-SPEC.md) — functional
   specification of the viewer/converter: loader behaviour, rendering,
   animation playback, HDRI environments, export matrix, extraction schemas,
   UI layout, acceptance tests with concrete expected values.

## Legal / interoperability note

The `.meshy` container format is Meshy's property. This documentation was
produced solely by observing files the account owner generated, to enable
interoperability with **their own** assets. It deliberately contains no Meshy
source code, no decompiled or disassembled material, and no description of any
Meshy runtime's internals — only the observable, independently verifiable
behaviour of the files themselves. Don't use it on assets you don't have
rights to.
